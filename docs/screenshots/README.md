# 스크린샷 (증빙 자료)

배포 주소(https://….vercel.app)에서 **진짜 AI 응답**으로 찍은 사진을 이 폴더에 넣는다.
주소창에 `vercel.app` 이 보이게 찍으면 "배포 환경" 증빙이 된다.

| 파일 이름 | 내용 |
|---|---|
| `desktop_home.png` | PC 홈 화면 |
| `desktop_ai_result.png` | PC AI 코디 결과 (LOOK 1~3) |
| `desktop_ai_empty.png` | 빈 입력 안내 ("필수값을 입력해 주세요") |
| `desktop_weather.png` | 오늘 날씨 자동 입력 안내 (✅ ○월 ○일 ○○: ○℃ · ○○) |
| `mobile_home.png` | 휴대폰 홈 |
| `mobile_menu.png` | 휴대폰 ≡ 메뉴 열린 화면 |
| `mobile_ai_result.png` | 휴대폰 AI 결과 |
| `desktop_dark.png` | 다크 모드 (보너스) |
| `ai_tool_*.png` | AI 코딩 도구(Claude) 대화 과정 캡처 |

⚠️ `.env` 파일 화면, Vercel 환경 변수 값, API 키가 보이는 화면은 절대 찍지 않는다.
